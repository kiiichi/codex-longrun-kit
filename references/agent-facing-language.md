# Agent-facing language rules

Use language that is short, operational, and hard to misinterpret.

Prefer:

- "Do not implement during initialization."
- "Ask one blocking question at a time."
- "Mark unknowns as `UNCONFIRMED`."
- "Fix exactly one ReviewQueue ticket."

Avoid:

- abstract wishes like "be careful"
- long essays in always-read files
- multiple conflicting sources of truth
- large blank templates

A long-run scaffold should reduce cognitive load, not become another source of context pollution.
