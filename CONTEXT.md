# Context

## Domain Terms

- **Runtime docs**: generated target-repo handoff files for one long-running task.
- **Target repo output**: namespaced artifacts under `docs/agent/longrun/`.
- **Artifact helper**: standard-library script that creates or normalizes runtime artifacts.
- **Plan**: confirm current state, target goal, source docs, blockers, and validation gates.
- **Longrun**: execute one milestone at a time under `LONGRUN.md`.
- **Closeout**: stop new work and record status, validation, risks, handoff, and resume action.
- **Review freeze**: product-code edits stop; review artifacts start.
- **Normalize feedback**: convert independent review reports into a draft repair queue.
- **HITL**: human decision required before continuing.
